# NU17112 MCU

**最后更新**: 2026-04-08
**来源文件**: hal/regdef.h, hal/sys.c, startup/ckcpu.ld, hal/overview.h

---

## 概述

NU17112 是 NuVolta 出品的 Qi 2.x 无线充电发射端专用 MCU，集成了丰富的模拟外设用于无线充电控制。

| 参数 | 值 |
|------|---|
| CPU 核心 | C-Sky CK802 (32-bit RISC) |
| 主频 | 36 MHz (可降至 6 MHz) |
| Flash | 120 KB (0x00002000 ~ 0x00020000) |
| SRAM | 7 KB (0x20000400 ~ 0x20002000) |
| 内部时钟 | HIRC 8 MHz + PLL |
| 低速时钟 | LIRC 64 kHz |

## 外设资源

| 外设 | 数量 | 用途 |
|------|------|------|
| Timer | 4 (TMR0~3) | 系统 tick、协议定时 |
| EPWM | 2 通道 | Qi TX 全桥驱动 |
| BPWM | 1 | 辅助 PWM |
| ECAP | 5 通道 | 谐振频率捕获 |
| EADC | 6 通道 | Qi 模拟解调 |
| BADC | 16 通道 | 电池/电源测量 |
| I2C Master | 1 (软件) | 外部 IC 通信 |
| I2C Slave | 1 (硬件) | 预留 |
| UART | 2 | 调试串口 |
| GPIO | 4 Port (A/B/C/D) | IO 控制 |
| TCPC | 1 | TypeC 电源控制器 |
| FMC | 1 | Flash 编程 (512B 页) |
| WDT | 1 | 看门狗 |
| DMA | 1 | DMA 传输 |
| FSK | 2 | Qi FSK 调制 |
| DDM | 1 | 数字解调 |

|--------|------|

| 功能 | 阈值 |

## 引脚分配 (关键)

| 引脚 | 功能 | 说明 |
|------|------|------|
| PA0 | SCL1_S | I2C Slave 时钟 |
| PA1 | SDA1_S | I2C Slave 数据 |
| PA6 | I2C_SCL | I2C Master 时钟 (软件) |
| PA7 | I2C_SDA | I2C Master 数据 (软件) |
| PA4~PA5 | GPIO Out | 控制引脚 |
| PB0~PB1 | GPIO Out | 控制引脚 |
| PB6 | BADC_ADC7 | BAT2+ 采样 (÷3) |
| PC7 | BADC_ADC4 | Cell2 电压 (÷3) |

## Flash 布局

| 地址范围 | 大小 | 用途 |
|---------|------|------|
| 0x00002000 ~ 0x0001FFFF | 120 KB | APROM (固件代码) |
| 0x00001800 | ~100B | ProductInfo 存储区 |
| 0x20000000 ~ 0x200003FF | 1 KB | 配置区 (CFG) |

## 已知约束

1. **SRAM 极度有限**: 7KB 总计 (栈 + 堆 + 全局变量)，需严格控制变量大小
2. **协作式调度**: 无抢占，单次 task handler 执行不应超过 1ms
3. **Flash 页擦除**: 最小 512B，不支持字节粒度擦除
4. **结构体布局**: 修改 gd_t/ap_t 只能在末尾追加字段，禁止中间插入
