# WB7720 USB HID Bridge

**最后更新**: 2026-04-08
**来源文件**: app/usb_bridge.h, fml/_fml.c, .claude/references/specs/WB7720_USB_Bridge_接口规范.md

---

## 概述

WB7720 是 USB HID Bridge MCU，提供 NU17112 与 Windows PC 之间的数据通道。

| 参数 | 值 |
|------|---|
| I2C 地址 | 0x21 (NU17112 为 Master) |
| USB | HID 64B 报告, VID=0xFFFF, PID=0xFFFF |
| 缓冲区 | i2c_buff[256] — I2C 和 HID 共享 |
| 更新频率 | 47ms (FML_TASK 写入) |

## I2C 寄存器映射

### 遥测数据区 (0x00~0x36, NU17112 → WB7720)

| 地址 | 宏名 | 类型 | 单位 | 说明 |
|------|------|------|------|------|
| 0x00 | REG_SOC_PCT | u8 | % | 电量百分比 |
| 0x01~0x04 | REG_CAPACITY_MAH | u32 LE | mAh | 额定容量 (5000) |
| 0x05~0x06 | REG_VBAT_MV | u16 LE | mV | 总电压 |
| 0x07~0x08 | REG_IBAT_MA | s16 LE | mA | 电流 (正=充,负=放) |
| 0x09~0x0A | REG_TEMP_DC | s16 LE | 0.1°C | 电池温度 |
| 0x0B~0x0C | REG_CYCLE_COUNT | u16 LE | 次 | 循环次数 |
| 0x0D~0x0E | REG_R_INTERNAL_MOHM | u16 LE | mΩ | 内阻 |
| 0x0F~0x10 | REG_SOH_PCT_X100 | u16 LE | %×100 | SOH |
| 0x11~0x12 | REG_ERR_OVERTEMP_CNT | u16 LE | 次 | 过温次数 |
| 0x13~0x14 | REG_ERR_OVERVOLT_CNT | u16 LE | 次 | 过压次数 |
| 0x15~0x16 | REG_ERR_OVERCURR_CNT | u16 LE | 次 | 过流次数 |
| 0x17 | REG_CHARGE_STATE | u8 | enum | 0=待机,1=充电,2=放电 |
| 0x2C | REG_CELL_COUNT | u8 | 个 | 电芯数 (固定 2) |
| 0x2D~0x2E | REG_CELL1_VOLTAGE_MV | u16 LE | mV | Cell1 电压 |
| 0x2F~0x30 | REG_CELL2_VOLTAGE_MV | u16 LE | mV | Cell2 电压 |
| 0x35~0x36 | REG_PCB_TEMP_DC | s16 LE | 0.1°C | 板温 |

### 异常日志区 (0x37~0x4D, NU17112 滚动写入)

| 地址 | 宏名 | 类型 | 说明 |
|------|------|------|------|
| 0x37 | REG_EXC_TOTAL_COUNT | u8 | 异常记录总数 (0~5) |
| 0x38 | REG_EXC_CURRENT_IDX | u8 | 当前写入序号 |
| 0x39 | REG_EXC_READY | u8 | 0xA5=就绪, 0x00=写入中 |
| 0x3A~0x4D | REG_EXC_RECORD | u8[20] | BatteryExceptionRecord_t |

### 睡眠/唤醒 (0x4E~0x4F)

| 地址 | 宏名 | 说明 |
|------|------|------|
| 0x4E | REG_SLEEP_CMD | 写非零 → MCU stop |
| 0x4F | REG_WAKEUP_CMD | 写非零 → 恢复 USB |

### 工程模式 (0x50~0x89, PC → NU17112)

| 地址 | 宏名 | 说明 |
|------|------|------|
| 0x50 | REG_WORK_MODE | 0x00=用户, 0xA5=工程 |
| 0x51 | REG_TIME_SYNC | 写 0xCA 触发 |
| 0x60~0x66 | REG_ENG_CURRENT_DATE | 7B 日期时间 |
| 0x70~0x73 | REG_ENG_PROD_DATE | 4B 生产日期 |
| 0x80~0x81 | REG_ENG_CYCLE_COUNT | u16 循环次数 |
| 0x82~0x83 | REG_ENG_VIRTUAL_CELL1 | u16 虚拟 Cell1 电压 |
| 0x84~0x85 | REG_ENG_VIRTUAL_CELL2 | u16 虚拟 Cell2 电压 |
| 0x86~0x87 | REG_ENG_VIRTUAL_TEMP | s16 虚拟温度 |
| 0x88 | REG_ENG_ERASE_CMD | 0xEE=擦除, 0xAA=刷新 |
| 0x89 | REG_ENG_CMD_STATUS | 状态反馈 |

### 生产模式 (0x90~0xF5, 双向复用)

| 地址 | 宏名 | 长度 | 说明 |
|------|------|------|------|
| 0x90 | PROD_MODE_FLAG | 1B | 0xB5=进入生产模式 |
| 0x91 | PROD_WRITE_STATUS | 1B | 写入状态 |
| 0x92~0xA5 | PROD_MANUFACTURER | 20B | 厂商名 |
| 0xA6~0xB9 | PROD_MODEL | 20B | 型号 |
| 0xBA~0xCD | PROD_BATTERY_MFR | 20B | 电池厂商 |
| 0xCE~0xE1 | PROD_BATTERY_MODEL | 20B | 电池型号 |
| 0xE2~0xF5 | PROD_PROD_DATE | 20B | 生产日期 |

## 数据流

```
NU17112 (每47ms)
  → hal_i2cm_write_multi_bytes(0x21, reg, data, len)
    → WB7720 i2c_buff[256]
      → USB HID 64B 报告 (1Hz round-robin)
        → Windows 上位机
```

## WB7720 单位转换

| 字段 | i2c_buff 单位 | HID 报告单位 | 转换 |
|------|-------------|-------------|------|
| 电压 | mV | V×100 | ÷10 |
| 电流 | mA | A×100 | ÷10 |
| 功率 | — | W×10 | (V×I)÷100000 |
| 温度 | 0.1°C | 0.1°C | 直传 |
| SOH | %×100 | %×100 | 直传 |
