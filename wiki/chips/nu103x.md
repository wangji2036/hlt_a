# NU103x WPC 模拟前端 (AFE)

**最后更新**: 2026-04-08
**来源文件**: fml/nu103x.c, fml/nu103x.h

---

## 概述

NU103x 是 NuVolta 的 Qi 无线充电模拟前端芯片，负责 ASK 解调、Q-factor 检测、谐振频率测量等模拟信号处理。

| 参数 | 值 |
|------|---|
| 通信方式 | 脉冲通信 (非标准 I2C) |
| 用途 | Qi TX 模拟信号处理 |
| OCP | 8A / 10A 可配 |
| DDM | 模拟/数字解调模式 |

## 功能寄存器/状态位

| 状态位 | 说明 |
|--------|------|
| OCP_Threshold | 过流保护阈值: 8A 或 10A |
| Low_Power_Mode | 低功耗模式状态 |
| Q_Measurement | Q-factor 测量使能 |
| VDD_LDO_Status | LDO 输出状态 |
| DRVH1/DRVH2 | 驱动输出模式 |
| DDM_Output_Mode | DDM 输出模式选择 |
| Comp_Hysteresis | 比较器迟滞: 12.5mV / 30mV |

## 在 WPC 系统中的角色

```
无线充电 RX 设备
  ↓ 电磁耦合
发射线圈
  ↓
NU103x AFE
  ├─ ASK 解调 → 数据包 → fml/ask.h → FML_TASK
  ├─ Q-factor → ECAP 捕获 → fml/qdt.c → FOD 检测
  └─ 谐振频率 → 频率跟踪 → PID 控制
```

## 初始化序列

在 main.c L60-75 执行 POR (上电复位) 初始化:
1. 检测无线充电设备是否在位
2. 配置 DDM 模式
3. 设置 OCP 阈值
4. 使能 Q-factor 测量
