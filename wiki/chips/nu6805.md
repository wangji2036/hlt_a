# NU6805 / SW7201 双向 Buck-Boost 控制器

**最后更新**: 2026-04-08
**来源文件**: hal/nu6805.c, hal/nu6805.h, power/buckboost.c, power/buckboost.h

---

## 概述

NU6805 (兼容 SW7201) 是双向 Buck-Boost DC-DC 转换器，支持电池充电和放电。通过 I2C 与 NU17112 通信。

| 参数 | 值 |
|------|---|
| I2C 地址 | 0x3C |
| 功能 | 双向 Buck-Boost 充放电 |
| 模式 | 充电 (1) / 放电 (2) / 关断 (0) |
| ADC | 内置多通道 (VBAT, IBAT, VBUS, IBUS, NTC) |

## 关键配置序列

### 充电模式初始化
```
1. 设置 Charger_Vbat_Vol (0x30) → CV 电压 (如 4350mV)
2. 设置 Charger_Ibus/Ibat_Limit → 充电电流
3. 写 Mode_Ctrl (0x0D) = 0x01 → 充电模式
```

### 放电模式初始化
```
1. 设置 Dischg_Vbus_Vol (0x20) → 输出电压 (如 5V/9V/12V)
2. 设置 Dischg_Ibus/Ibat_Limit → 放电电流
3. 写 Mode_Ctrl (0x0D) = 0x02 → 放电模式
```

## 已知注意事项

1. **IC 复位检测**: 需定期读 0x0F 检查是否意外复位
2. **ADC 读取序列**: 先写 ADC_Type(0x10)，再读 High(0x11) + Low(0x12)
3. **NTC 保护**: 温度过高时 IC 自动关断，需配合固件侧 NTC 检测
