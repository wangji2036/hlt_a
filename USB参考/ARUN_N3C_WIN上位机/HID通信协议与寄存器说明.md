# HID 通信协议与寄存器说明

## 一、基本参数

| 参数 | 值 | 说明 |
|------|-----|------|
| VID | 0xFFFF | 厂商 ID |
| PID | 0xFFFF | 产品 ID |
| Usage Page | 0xFF00 | 厂商自定义 |
| Usage ID | 0x01 | 厂商自定义 |
| 报文长度 | 64 字节 | 所有消息统一长度 |
| 固件版本 | NANFU_USB_1052_20260121A | 当前适配版本 |

---

## 二、上位机 → 下位机（下发命令）

所有写操作格式：

```
[0x00 Report ID] + [CMD] + [payload] + [0x00 填充至 64 字节]
```

> `0x00` 前缀为 hidapi 库对无 Report ID 设备的要求，实际发送 65 字节。

### 2.1 命令码汇总

| 命令码 | 名称 | 说明 |
|--------|------|------|
| 0x01 | CMD_READ_STATUS | 请求电池状态 / 异常日志 |
| 0x02 | CMD_READ_DEVICE_INFO | 请求设备信息 |
| 0x0C | CMD_WRITE_REGISTER | 写入工程模式寄存器 |
| 0x10 | CMD_FAST_CHARGE_ACTIVATE | 激活快充模式 |

### 2.2 CMD_READ_STATUS (0x01)

请求下位机上报电池遥测数据或异常日志。

```
[0x00][0x01][0x00 × 63]
```

### 2.3 CMD_READ_DEVICE_INFO (0x02)

请求下位机上报设备制造商、电芯厂商、生产日期、序列号等信息。

```
[0x00][0x02][0x00 × 63]
```

### 2.4 CMD_WRITE_REGISTER (0x0C)

向下位机写入寄存器数据（工程模式使用）。

```
[0x00][0x0C][REG_ADDR][DATA_LEN][DATA...][0x00 填充]
```

| 字节偏移 | 字段 | 说明 |
|---------|------|------|
| 0 | 0x0C | 命令码 |
| 1 | REG_ADDR | 寄存器地址 |
| 2 | DATA_LEN | 数据字节数 |
| 3 ~ N | DATA | 实际数据 |
| N+1 ~ 63 | 0x00 | 填充 |

### 2.5 CMD_FAST_CHARGE_ACTIVATE (0x10)

激活快充模式。

```
[0x00][0x10][0x00 × 63]
```

## 三、下位机 → 上位机（上报数据）

### 3.1 通用协议头（9 字节）

所有上报报文共享相同的协议头：

| 偏移 | 字段 | 类型 | 值 / 说明 |
|------|------|------|-----------|
| 0-2 | SOF | u8[3] | 固定 `05 A5 5A`（帧起始标记） |
| 3 | Ver | u8 | 协议版本，当前为 `0x02` |
| 4 | Type | u8 | 消息类型：`0x01` 遥测 / `0x02` 异常日志 |
| 5-6 | Seq | u16 LE | 序列号（递增） |
| 7-8 | Len | u16 LE | 有效载荷长度（字节） |

### 3.2 Type 0x01 — 电池遥测数据

从偏移 9 开始的有效载荷：

| 相对偏移 | 字段 | 类型 | HID 上报单位 | 显示换算 |
|---------|------|------|-------------|----------|
| +0 | SOC（电量百分比） | u8 | % | 直接显示 |
| +1 ~ +4 | 容量 | u32 LE | mAh | 直接显示 |
| +5 ~ +6 | 总电压 | u16 LE | V×100 | ÷100 → V |
| +7 ~ +8 | 总电流 | s16 LE | A×100 | ×10 → mA |
| +9 ~ +10 | 功率 | s16 LE | W×10 | ÷10 → W |
| +11 | 充电状态 | u8 | enum | 0=待机, 1=充电, 2=放电 |
| +12 ~ +13 | 循环次数 | u16 LE | 次 | 直接显示 |
| +14 ~ +15 | 电池温度 | s16 LE | °C×10 | ÷10 → °C |
| +16 ~ +17 | 板温 | s16 LE | °C×10 | ÷10 → °C |
| +18 | 电芯数 | u8 | 个 | 固定为 2 |
| +19 ~ +20 | 电芯 1 电压 | u16 LE | V×100 | ÷100 → V |
| +21 ~ +22 | 电芯 2 电压 | u16 LE | V×100 | ÷100 → V |
| +23 ~ +24 | 内阻 | u16 LE | mΩ | 直接显示 |
| +25 ~ +26 | SOH（健康度） | u16 LE | pct×100 | ÷100 → % |
| +27 ~ +28 | 过温异常次数 | u16 LE | 次 | 直接显示 |
| +29 ~ +30 | 过压异常次数 | u16 LE | 次 | 直接显示 |
| +31 ~ +32 | 过流异常次数 | u16 LE | 次 | 直接显示 |
| +33 | 异常日志条数 | u8 | 条 | 直接显示 |
| +34 | 品牌名长度 | u8 | 字节 | — |
| +35 ~ +41 | 品牌名 | char[] | ASCII | 字符串显示 |
| 末尾 2 字节 | CRC16 | u16 LE | — | 可选校验 |

### 3.3 Type 0x02 — 异常日志

从偏移 9 开始的有效载荷：

| 相对偏移 | 字段 | 类型 | 说明 |
|---------|------|------|------|
| +0 | OffsetPage | u8 | 分页偏移 |
| +1 | ReturnCount | u8 | 本次返回条数（0-5） |
| +2 起 | ExceptionLog[] | 12B × N | 异常日志条目数组 |

**每条异常日志（12 字节）：**

| 相对偏移 | 字段 | 类型 | 说明 |
|---------|------|------|------|
| +0 ~ +1 | 年 | u16 LE | |
| +2 | 月 | u8 | |
| +3 | 日 | u8 | |
| +4 | 时 | u8 | |
| +5 | 分 | u8 | |
| +6 | 秒 | u8 | |
| +7 | 异常类型 | u8 | 0=过温, 1=过流, 2=过压 |
| +8 ~ +11 | 异常值 | s32 LE | ÷100 → 对应单位 |

异常值单位对照：

| ErrType | 含义 | 值的单位 | 换算 |
|---------|------|---------|------|
| 0 | 过温 | °C×100 | ÷100 → °C |
| 1 | 过流 | A×100 | ÷100 → A |
| 2 | 过压 | V×100 | ÷100 → V |

## 四、通信节奏

- 上位机每约 **1 秒**发送一次 `CMD_READ_STATUS (0x01)`
- 下位机按以下模式交替回复：
  - 第 1~4 次请求 → 回复 **Type 0x01**（遥测数据）
  - 第 5 次请求 → 回复 **Type 0x02**（异常日志）
  - 循环往复
- 上位机通过检查 `data[4]`（Type 字段）判断回复类型
- 所有多字节整数均为 **小端序（Little-Endian）**

## 六、下位机寄存器

下位机存在两层寄存器模型：

- **BMS I2C 寄存器**：由电池管理芯片提供，固件通过 I2C 总线读取（只读）
- **工程模式寄存器**：固件自身定义，上位机通过 HID `CMD_WRITE_REGISTER (0x0C)` 写入（可写）

### 6.1 BMS I2C 寄存器（只读）

| I2C 地址 | 字段 | 类型 | 原始单位 | 固件处理 | HID 上报单位 |
|----------|------|------|----------|---------|-------------|
| 0x00 | SOC（电量百分比） | u8 | % | 直传 | % |
| 0x01-0x04 | 容量 | u32 LE | mAh | 直传 | mAh |
| (voltage) | 总电压 | u16 | mV | ÷10 | V×100 |
| (current) | 总电流 | s16 | mA | ÷10 | A×100 |
| — | 功率 | s16 | — | (mV×mA)/100000 | W×10 |
| 0x17 | 充电状态 | u8 | enum | 直传 | 0=待机, 1=充电, 2=放电 |
| 0x0B-0x0C | 循环次数 | u16 LE | 次 | 直传 | 次 |
| 0x09-0x0A | 电池温度 | s16 LE | 0.1°C | 直传 | °C×10 |
| 0x35-0x36 | 板温 | s16 LE | 0.1°C | 直传 | °C×10 |
| (cell1) | 电芯 1 电压 | u16 | mV | ÷10 | V×100 |
| (cell2) | 电芯 2 电压 | u16 | mV | ÷10 | V×100 |
| 0x0D-0x0E | 内阻 | u16 LE | mΩ | 直传 | mΩ |
| 0x0F-0x10 | SOH（健康度） | u16 LE | 0.01% | ×100 | pct×100 |

### 6.2 工程模式寄存器（可写）

通过 `CMD_WRITE_REGISTER (0x0C)` 写入，载荷格式：`[0x0C][REG_ADDR][DATA_LEN][DATA...]`

| 寄存器地址 | 名称 | 数据长度 | 数据格式 | 说明 |
|-----------|------|---------|---------|------|
| **0x50** | REG_WORK_MODE | 1 字节 | 固定写 `0xA5` | 解锁工程模式，必须首先写入 |
| **0x60** | REG_ENG_CURRENT_DATE | 4 字节 | u16 LE（年）+ u8（月）+ u8（日） | 写入当前日期 |
| **0x70** | REG_ENG_PRODUCTION_DATE | 4 字节 | u16 LE（年）+ u8（月）+ u8（日） | 写入生产日期 |
| **0x80** | REG_ENG_CYCLE_CHG_COUNT | 2 字节 | u16 LE | 写入循环充电次数（范围 0-65535） |

### 6.3 工程模式写入序列

必须按以下顺序依次执行，每步间隔 **50ms**：

```
步骤 1: 解锁工程模式
  → [0x00][0x0C][0x50][0x01][0xA5][0x00 × 59]

步骤 2: 写入当前日期
  → [0x00][0x0C][0x60][0x04][年Lo][年Hi][月][日][0x00 × 56]

步骤 3: 写入生产日期
  → [0x00][0x0C][0x70][0x04][年Lo][年Hi][月][日][0x00 × 56]

步骤 4: 写入循环充电次数
  → [0x00][0x0C][0x80][0x02][次Lo][次Hi][0x00 × 58]
```

**示例**（日期 2026/01/29，循环 100 次）：

```
步骤 1: 00 0C 50 01 A5 00 00 00 ...
步骤 2: 00 0C 60 04 EA 07 01 1D 00 00 ...   (0x07EA = 2026)
步骤 3: 00 0C 70 04 EA 07 01 1D 00 00 ...
步骤 4: 00 0C 80 02 64 00 00 00 ...          (0x0064 = 100)
```

---

## 七、关键说明

1. **Report ID 前缀**：hidapi 库要求所有写入命令前加 `0x00`，实际发送 65 字节
2. **字节序**：所有多字节整数均为小端序（Little-Endian）
3. **电芯数固定为 2**：CellCount 在固件中硬编码
4. **异常计数硬编码**：过温/过压/过流异常次数目前固件中为固定值
5. **异常日志条数硬编码**：ExceptionLogCount 固件中固定为 3
6. **温度智能检测**：上位机对温度值 < 100 视为直接 °C，≥ 100 则 ÷10 转换
7. **读取超时**：HID read 操作默认 1000ms 超时
8. **线程安全**：上位机应避免对 HID 设备的并发读写
