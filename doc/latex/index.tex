{\bfseries{NU171xx is a high efficiency, high integration Qi 2.\+x compliant transmitter IC for wireless charging with input voltage from 3V to 21V.}} ~\newline
 It integrates low Rdson Full bridge FETs and gate driver, 32bit 36MHz MCU core, 8kB SRAM and 128kB Flash, and fast charging block TCPC/\+PD/\+BC1.\+2/\+QC/\+FCP/ SCP/\+AFC.\doxysection{Introduction}\label{index_autotoc_md0}
This project is aimed to develop a high-\/efficiency, high-\/integration Qi 2.\+x compliant transmitter IC for wireless charging with input voltage from 3V to 21V. ~\newline
