\doxysubsection{Detailed Description}
I2C Slave HAL module driver.~\newline
 The functionalities of the I2C Slave peripheral as below\+:~\newline
 


\begin{DoxyItemize}
\item Initialization and de-\/initialization functions. ~\newline

\item Uart transmit a character. ~\newline

\begin{DoxyItemize}
\item Register the interrupt callback function. ~\newline

\item Retarget the fputc function to the uart transmit function. ~\newline

\item UART1 and UART2 Interrupt handler. ~\newline

\end{DoxyItemize}
\end{DoxyItemize}

(+) Supports 7-bit addressing.
