void hal_uart_init ( TS_UART * uart)

Initialize the UART. Mason 17111 have two UARTs, UART1 and UART2.

  • The UART is configured as a USCI_A0 module.
  • The baud rate is set to 250K.
    Parameters
    uartUART1 or UART2
    Returns
    None
    Note
