## 1. 测试概述

### 1.1 测试目标

验证工程模式（Engineering Mode）在 NU17112 + WB7720 + Windows PC 三方系统中的端到端功能正确性，确保：

1. 虚拟参数注入链路完整且安全
2. 异常记录触发/存储/传输/显示全链路正确
3. 擦除和刷新命令可靠执行
4. 模式进入/退出不留残余状态
5. 写保护机制有效防止误操作

### 1.2 测试范围

| 范围 | 包含 | 不包含 |
|------|------|--------|
| 系统层 | NU17112 固件 + WB7720 固件 + Windows 上位机 | 其他协议测试 (Qi/PD/QC) |
| 功能域 | 工程模式全部功能 | 用户模式遥测、生产模式 |
| 文件域 | usb_bridge.c, bat_record.c, WB7720 main.c, battery_monitor.py | HAL/FML 底层驱动 |

### 1.3 测试方法

| 方法 | 适用阶段 | 需要硬件 |
|------|---------|---------|
| 代码审查 (Code Review) | Phase 0 | 否 |
| 联机功能测试 (Manual) | Phase 1-4 | 是 |
| 边界/压力测试 (Manual) | Phase 5 | 是 |

## 2. 前置条件

### 2.1 硬件准备

- [ ] ARUN IP162N 开发板已组装并可正常工作
- [ ] WB7720 USB Bridge 模块已焊接并通过 I2C 通信测试
- [ ] USB Type-C 线连接开发板到 Windows PC
- [ ] UART 调试线已连接 (115200 baud)
- [ ] 电池已安装，SOC > 20%

### 2.2 软件准备

- [ ] NU17112 固件已编译通过 (CDS 无警告)，已烧录到开发板
- [ ] WB7720 固件已烧录 (Keil MDK 编译)
- [ ] Windows 上位机 `battery_monitor.py` 可运行 (Python 3.8+, hidapi)
- [ ] UART 终端工具已打开 (PuTTY/MobaXterm)

### 2.3 验收标准

| 等级 | 标准 | 说明 |
|------|------|------|
| **P0 (必须通过)** | Phase 1-2 全部 PASS | 基础连通性和核心功能 |
| **P1 (应当通过)** | Phase 3-4 通过率 ≥ 90% | 异常记录全链路和命令处理 |
| **P2 (期望通过)** | Phase 5 通过率 ≥ 80% | 边界条件和压力测试 |

## 4. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|------|------|---------|
| WB7720 exc_cache 擦除不清理 | Medium | PC 端 seen_ids 清除可缓解；完整验证需拔插 USB |
| 846ms 延迟导致测试不稳定 | Medium | 所有等待时间翻倍，推荐 2-3s |
| UART 日志缓冲区溢出丢日志 | Low | 降低 printk 频率或使用更高波特率 |
| 虚拟温度 0°C 无法测试 | Low | 已知限制，使用 ±1 (0.1°C) 替代 |
| Flash 写入次数限制 | Low | 单次测试周期内不会超限 (寿命 >10K 次) |
