# TW-25071 定制数码管/背光板驱动原理分析报告

---

## 1. 硬件概述

该显示器件仅通过 **7 个引脚 (PIN1 - PIN7)** 控制面板上的 5 组显示区域。内部采用查理复用技术，引脚同时作为阳极和阴极复用，以此减少 I/O 占用。

### 1.1 关键映射结论 (物理 vs 逻辑)

屏幕物理上从左到右的显示区域，**不对应**逻辑上的 DIG1-DIG5 顺序。经分析原理图真值表及 PCB 走线示意图，实际映射关系如下：

| 物理位置 (从左至右)       | 显示内容描述                        | 对应逻辑组 (Group) |
| :------------------------ | :---------------------------------- | :----------------- |
| **位置 1 (最左侧)** | **温度图标 / 电池框 / 4A-4G** | **DIG 4**    |
| **位置 2**          | 数字 "1" (笔画 1A-1G)               | **DIG 1**    |
| **位置 3 (正中间)** | 数字 "2" (笔画 2A-2G)               | **DIG 2**    |
| **位置 4**          | 数字 "3" (笔画 3A-3G)               | **DIG 3**    |
| **位置 5 (最右侧)** | 功能图标 (℃, %, IN,OUT)            | **DIG 5**    |

---

## 2. 驱动逻辑详解

由于引脚复用，驱动时 **严禁** 将非活动引脚直接接地或接电源，必须配置为 **高阻态 (High-Z / Input模式)**。

### 2.1 I/O 状态定义

对任意时刻的单一操作：

* **阳极 Pin (Anode)**：输出 **高电平 (High / VCC)**
* **阴极 Pin (Cathode)**：输出 **低电平 (Low / GND)**
* **其余所有 Pin**：配置为 **输入模式 (Input Floating / High-Z)**

## 3.函数定义伪代码

### 3.1 函数

函数1： 单独控制警告图标 ，输入变量为灭或者亮。

函数2：单独控制重置图标 ，输入变量为灭或者亮。

函数3：单独控制电池图标，输入变量为灭或者亮。

函数4：单独控制温度计图标，输入变量为灭或者亮。

函数5：控制中间三位数码管显示，输入变量为0-100的数字。

函数6：单独控制℃ 符号，输入变量为灭或者亮。

函数7：单独控制IN图标，输入变量为灭或者亮。

函数8：单独控制圆形图标/绿色50，输入变量为灭或者亮。

函数9：单独控制百分号 (%)，输入变量为灭或者亮。

函数10：单独控制OUT 图标，输入变量为灭或者亮。
